# AI-дайджест для новичков 🤖

Конверсионный сайт с карточками про Claude Code: первые проекты, промпты и ошибки.
Тёмная неоновая тема, поиск, фильтр по тегам — работает на телефоне и компьютере.

## Быстрый старт (Windows)

### Шаг 1. Установите Python
Скачайте с https://python.org и при установке **обязательно поставьте галочку
«Add Python to PATH»**.

Проверка в командной строке (`cmd`):

```bat
python --version
```

Если вместо версии открывается Microsoft Store — используйте команду `py` вместо `python`
(она тоже ставится с python.org):

```bat
py --version
```

### Шаг 2. Создайте виртуальное окружение (рекомендуется)

В папке проекта откройте `cmd`:

```bat
cd C:\путь\к\проекту
py -m venv venv
venv\Scripts\activate
```

После активации в начале строки появится `(venv)`.

### Шаг 3. Установите Flask

```bat
pip install flask
```

или, если pip жалуется:

```bat
py -m pip install flask
```

### Шаг 4. Запустите сайт

```bat
python app.py
```

Откройте в браузере: **http://127.0.0.1:5000**

### Остановка сервера

Нажмите `Ctrl + C` в окне терминала, где запущен сервер.

## PowerShell? Те же команды

PowerShell часто ругается на скрипты активации. Разрешите их один раз
(от администратора):

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Затем:

```powershell
py -m venv venv
.\venv\Scripts\Activate.ps1
pip install flask
python app.py
```

## Возможные проблемы (Windows)

| Проблема | Решение |
|---|---|
| «python не является внутренней или внешней командой» | Не включён PATH. Переустановите Python с галочкой «Add Python to PATH» или используйте `py` |
| Порт 5000 занят | Поменяйте последнюю строку в `app.py` на `app.run(debug=True, port=8000)` |
| Антивирус/SmartScreen блокирует | Добавьте исключение для Python или запускайте из доверенной папки |
| Кириллица «кракозябрами» в cmd | Выполните `chcp 65001` перед запуском |
| Файл `content.json` не найден | Запускайте `python app.py` из папки проекта (где лежит `content.json`) |

## Структура проекта

```
├── app.py                  # Flask: читает content.json, отдаёт страницу + /api/cards
├── content.json            # 10 карточек (заголовок, описание, ссылка, теги)
├── requirements.txt        # зависимости (flask)
├── templates/
│   └── index.html          # шаблон главной страницы
└── static/
    ├── css/style.css       # тёмная неоновая тема, анимации, адаптив
    └── js/script.js        # поиск и фильтр по тегам
```

## Как добавить свою карточку

Откройте `content.json` и добавьте объект в конец списка:

```json
{
  "title": "Заголовок карточки",
  "description": "Короткое описание — о чём материал и чем он полезен новичку.",
  "url": "https://ссылка-на-материал",
  "tags": ["промпты", "ошибки"]
}
```

Сохраните файл и перезапустите сервер — карточка появится автоматически,
а её теги добавятся в фильтр.
